## 🙌 使用

| 操作 | 按键 |
|---|---|
| 呼出 | 瞄准 + 近战E |
| 上 / 下 | 瞄准 / 开火 |
| 确认 | 交互键F |
| 返回 / 关闭 | 近战E |

飞行开启后：跳上升、蹲下降、冲刺加速、摇杆平移。

菜单在 **左下角** 三行面包屑，约 4 秒刷新。开关项显示 `已启用`。
成功 / 失败 / 已启用 / 已关闭 等提示打在 **屏幕正中**。

## ❓ 常见问题

**Q：菜单显示成方块 / 编译报错？**
用上面的自定义编译器。原版编译器只吃 ASCII。

**Q：疫情爆发的 BossRush 怎么用？**
两个 Boss 的解锁状态都是**全局**的，但只有站在对的图上才能开打：

- **【```根除计划```】 奥达（疗养院）**：任意区域按一次「BossRush 奥达」→ 切到**疗养院** → 再按一次。
- **【```反转计划```】 军团长（鲁卡）**：**要在鲁卡上**按一次「BossRush 军团长」（这一步只是写入解锁状态，当次不会开）→ 切走 → 切回**鲁卡** → 再按一次。

**每次重启客户端都要重做这一步**：解锁状态只活到本次游戏进程结束。

**Q：为什么在疫情爆发里按 BossRush 提示「尚未注册」？**
同上——解锁状态是「写入之后**下一次**载入地图」才生效的。按提示切一次图再来。

**Q：换区之后武器 / PAP 等级 / 特长还在吗？**
在。疫情爆发内部换区走的是游戏自己的换区流程，会先保存玩家状态再切。只有用 `map()` 那种硬切才会丢。

**Q：会不会封号？**
见上面的免责声明。**只在单人 / 私人模式用。**
